# Zip images gallery

View images from a zip file on your device without exacting it. I made this app for personal use.

## Description
This is for viewing images from a zip (have not tested other archive types) file that you got somewhere on the Internet, without exacting it. <br>
This application is a single page app to view images from zip file. <br>
This application work on Linux and Android. No permission required on Android.
## How to use:
- Pick a zip file from your device's file picker.
- Get images from that ZIP file to display it on screen.
- Tap on an image to view it in gallery mode (zoom and move to the next or previous images).
